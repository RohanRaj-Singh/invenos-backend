- run/production/return keys scoped by company.

**Accounting**
- composition COGS per company;
- production cost/stock per company;
- reversal average per company;
- incomplete cost flagged per company;
- simple product regression.

**Migration**
- fresh install at target HEAD;

- rollback constraints on a disposable database.
